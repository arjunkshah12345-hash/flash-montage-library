Take all of it

With the skill installed, one command fetches everything into it. Run it again to resume; add --only cosmos,botanical for a part.

python3 -I ~/.agents/skills/flash-montage/scripts/get_library.py

Without the skill, clone the repository. Every file's licence, creator, source page, size, ground and palette is one line of manifest.jsonl.

git clone --depth 1 https://github.com/arjunkshah12345-hash/flash-montage-library

Licences: CC0 1.0, the Public Domain Mark, NASA media guidelines (credit NASA where you can; no endorsement implied), and stills generated by the flash-montage specimens, dedicated CC0. Two Flickr Commons items carry “no known copyright restrictions”. The full list is in CREDITS.md.
